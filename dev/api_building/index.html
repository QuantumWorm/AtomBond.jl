API: analysis and building

Analysis

AtomBond.Bond — Type

A bond from atom i to the image of atom j displaced by shift lattice vectors.

source
AtomBond.bond_cutoff — Method

Longest distance at which elements a and b count as bonded: tolerance times the sum of covalent radii, but at least the sum + 0.3 Å (which only matters for light atoms: H–H in H2 is 0.741 Å, 1.15 × 0.62 = 0.713 Å; F–F in F2 is 1.414 Å, 1.15 × 1.14 = 1.311 Å).

source
AtomBond.coordination — Method

AtomBond.find_bonds — Method
find_bonds(c; tolerance=1.15, min_length=0.4, metal_metal=:auto, cutoffs=Dict()) -> Vector{Bond}

Atoms i and j are bonded when min_length < d ≤ max(tolerance * (r_i + r_j), r_i + r_j + 0.3 Å), with r the covalent radius. cutoffs can raise that limit for given element pairs, e.g. Dict((:C, :Ga) => 2.77) (keys in alphabetical order, as pairkey makes them). Bonds across periodic boundaries are included; each bond is listed once.

Covalent radii of metals are large enough that cation–cation pairs in oxides and nitrides (Ti–Ti in rutile, Hf–Hf in HfO₂) would count as bonded. With metal_metal=:auto such bonds are kept only when every species is a metal (metals and alloys); pass true/false to force it.

add_bridge(c, a, b, third; element=:O, offset=0.5, flip=false, min_distance=0.5) -> Crystal

Add a bridging atom (oxygen by default) between Cartesian positions a and b (two atoms, possibly periodic copies) at bridge_position with the third atom's position third fixing the plane and the side. Refuses a position closer than min_distance Å to any atom.

AtomBond.periodic_box — Method
periodic_box(c; vacuum=10.0, cubic=false) -> Crystal

Put a molecule (a structure that is not periodic) into a periodic box for plane-wave codes (CASTEP, VASP, QE): an orthorhombic cell vacuum Å larger than the molecule along x, y and z (cubic: all three equal), with the molecule in the middle. The result is periodic, so its cell is shown and exported; k-points along the vacuum directions are 1 (Γ).

AtomBond.rotate_atoms — Method
rotate_atoms(c, angle, axis; center=centroid, atoms=all, images=nothing) -> Crystal

Rotate all atoms (or the indices in atoms) by angle degrees about the Cartesian axis through center (Å; default: the centroid of the rotated atoms). The cell stays fixed. images (one lattice shift per rotated atom) rotates those periodic copies instead, so a group that crosses a cell face turns as one piece.

AtomBond.nanotube — Method
nanotube(n, m; bond=1.4226, periods=1, vacuum=10.0, species=(:C, :C)) -> Crystal

A single-wall (n, m) nanotube: the honeycomb sheet rolled along the chiral vector n a₁ + m a₂. The tube axis is c, periodic, with periods translational periods in the cell; a and b are square with vacuum Å between the walls of neighbouring images and are not periodic (pbc = (false, false, true)). bond is the nearest-neighbour distance before rolling (graphite's by default); species puts one element on each sublattice, e.g. (:B, :N) for a BN nanotube (give the B–N distance of hexagonal BN as bond). The tube is an ideal rolled sheet: relax it before use.

nanotube(6, 5)                 # chiral, semiconducting, 364 atoms
nanotube(5, 5; periods=4)      # armchair, 4 periods along c

AtomBond.prototype_crystal — Function
prototype_crystal(name, elements, abc, angles=(90, 90, 90); title="") -> Crystal

A new structure: "Empty cell" (lattice abc, angles, no atoms) or one of the prototypes in PROTOTYPES ("Diamond", "Zincblende", "Rocksalt", "Wurtzite", ...) with elements (symbols, as many as the prototype needs) on its sites. Cubic prototypes use abc[1] only; hexagonal ones abc[1] and abc[3].

source
AtomBond.supercell — Method
supercell(c, n1, n2, n3) -> Crystal
supercell(c, P) -> Crystal

Repeat the cell n1×n2×n3 times, or more generally build the cell with vectors (a', b', c') = (a, b, c) * P for an integer matrix P with det(P) > 0. For example P = [1 -1 0; 1 1 0; 0 0 1] gives the √2×√2 rotated cell.

source
AtomBond.add_vacuum — Method
add_vacuum(c, vacuum) -> Crystal

Replace c by a vector along the normal of the ab plane so that vacuum Å of empty space lie between the top and bottom atoms of neighbouring images. Atoms keep their Cartesian positions apart from a shift along the normal that centres them; in-plane coordinates are wrapped into the cell.

source
AtomBond.best_termination — Method
best_termination(c, hkl) -> shift

Try a cut between every pair of neighbouring atomic planes of the (hkl) surface cell and return the shift that breaks the fewest bonds (ties: the lowest shift). For Si(111) this picks the cut between bilayers (one dangling bond per surface atom) rather than inside a bilayer (three).

source
AtomBond.slab — Method
slab(c, hkl; layers=4, vacuum=15.0, shift=:auto) -> Crystal

Cut a slab of layers (hkl) repeat units from bulk crystal c. One layer is one period of the surface cell along its normal (e.g. one cubic lattice constant for Si (001) from the conventional cell). With vacuum > 0 the c vector is made normal to the surface and vacuum Å of empty space separate the slab from its periodic image (the atoms are centred). shift chooses the termination (see surface_cell); :auto uses the cut that breaks the fewest bonds (best_termination).

source
AtomBond.stack_cells — Method
stack_cells(cells...; strain=false, tol=0.01) -> Crystal

Stack crystals along their c vectors (each block shifted by the c vectors of the blocks below). The blocks must share the in-plane cell (a, b) within relative tolerance tol; with strain=true, every block is strained in plane to the first one (no Poisson relaxation along c).

source
AtomBond.superlattice — Method
superlattice(A, B, hkl; layers=(4, 4), strain=false) -> Crystal

A/B superlattice along (hkl): layers[1] (hkl) repeat units of A followed by layers[2] of B, periodic in all directions.

source
AtomBond.surface_cell — Method
surface_cell(c, hkl; shift=0) -> Crystal

Bulk cell equivalent to c with a, b in the (hkl) plane and c pointing out of it, in standard orientation (surface normal along z). shift (fraction of one layer spacing) moves the origin along c, which picks the termination of slabs cut from it. The structure is still periodic bulk.
