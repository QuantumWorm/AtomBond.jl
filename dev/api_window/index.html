AtomBond.view_direction — Method
view_direction(lattice, which) -> (direction, up)

Presets: :a, :b, :c look down a lattice vector; :astar, :bstar, :cstar look down a reciprocal vector, i.e. straight onto the (100), (010), (001) planes. A 3-vector is taken as a lattice direction [uvw].

AtomBond.draw_structure! — Method
draw_structure!(lscene, crystal, settings) -> (DisplayModel, plots, atom_plot)

Draw atoms, bonds and (optionally) the unit cell into an LScene. For a fully non-periodic structure (molecule) the box is drawn as dashed grey lines. Returns the plots so a caller can remove them and redraw without touching the camera, and the atom plot separately for picking.

AtomBond.DISPLAY_STYLES — Constant

Display styles, as in Materials Studio:

  • :ball_and_stick — spheres scaled from covalent radii, cylinder bonds
  • :cpk — space-filling spheres at van der Waals radii, no bonds
  • :stick — bonds only; atoms are joints the size of the bonds
  • :line — bonds as thin lines; only unbonded atoms get a dot
source
AtomBond.ViewSettings — Type
ViewSettings(; kwargs...)

Display settings of a viewer (v.settings), set by keyword, e.g. ViewSettings(style=:cpk, show_bonds=false). Change a field of an open viewer and call redraw!. Main fields: style (see DISPLAY_STYLES), ball_scale, bond_radius, show_bonds, bond_stubs, show_cell, show_boundary_atoms, wrap_atoms, show_labels, show_triad, orthographic, bond_lengths (:selected or :all), show_bond_angles, show_dihedrals, show_coordinates, show_charges, show_magmoms and bond_cutoffs (per element pair).

AtomBond.atoms_dialog — Method
atoms_dialog(viewer; show=true) -> NamedTuple of the dialog's controls

Edit atoms window. Selected atoms: change the element (all selected atoms) and, for a single atom, set its position (fractional or Cartesian Å; for an image atom, ′, the position of that copy). Replace species: change every atom of one element into another. All changes are undoable.

source
AtomBond.bridge_dialog — Method
bridge_dialog(viewer; show=true) -> NamedTuple of the dialog's controls

Oxygen bridge window: select three atoms in the main window (the bond's two atoms, then a third). The bridging atom (O by default) goes at the bond's middle plus an offset v perpendicular to the bond, in the plane of the three atoms, towards the third (inside the triangle), or with "Other side" at −v. "Flip last bridge" moves the bridge just added to the other side. Undoable.

source
AtomBond.cell_dialog — Method
cell_dialog(viewer; show=true) -> NamedTuple of the dialog's controls

Cell and constraints window:

  • Cell: periodicity, lattice parameters, volume, density and vectors.
  • Periodic box: put a molecule in a box with a given vacuum (for plane-wave codes), or treat a structure as a molecule.
  • Lattice constraints for geometry optimization: presets or CASTEP-style numbers (0 fixed, equal numbers tied) with how VASP, QE and CASTEP get them.
  • Atom constraints: fix the fractional x, y, z of the selected atoms.

All changes are undoable and are written by the exporters.

source
AtomBond.export_dialog — Method
export_dialog(viewer; show=true) -> NamedTuple of the dialog's controls

Open the Export window: choose a format, folder and name, k-point spacing (the resulting mesh for the current structure is shown) and, for Quantum ESPRESSO, the cutoff and pseudopotential file pattern.

AtomBond.library_dialog — Method
library_dialog(viewer; show=true) -> NamedTuple of the dialog's controls

Structure library window: choose crystals, molecules or all, pick a structure and see its formula, symmetry, cell and source (paper, database entry), then Open it in the main window.

AtomBond.open_library! — Method
open_library!(viewer, entry or name) -> Bool

Replace the structure with one from the library (undoable). It is Untitled until saved, so Save never writes into the library. box (vacuum in Å) puts a molecule into a periodic box for plane-wave codes (cubic box by default).

source
AtomBond.rotate_dialog — Method
rotate_dialog(viewer; show=true) -> NamedTuple of the dialog's controls

Rotate atoms window: turn all atoms (or the selected ones) by an angle about an axis (Cartesian, a lattice direction, the line through two selected atoms, or the viewing direction) through a centre (the rotated atoms' centroid, the first selected atom, or a point). The cell is not rotated. A preview names the closest contact afterwards to catch overlaps. Undoable.

source
AtomBond.shift_dialog — Method
shift_dialog(viewer; show=true) -> NamedTuple of the dialog's controls

Shift atoms window: translate all atoms (or the selected ones) by a vector in fractional or Cartesian coordinates, optionally wrapping them into the cell afterwards; "Selected atom → origin" fills in the shift that puts the selected atom at (0, 0, 0). A second section wraps atoms that are outside the cell back in by whole lattice vectors. Both are undoable.

source
AtomBond.supercell_dialog — Method
supercell_dialog(viewer; show=true) -> NamedTuple of the dialog's controls

Supercell window: repeat the cell n1 × n2 × n3, or give the new cell vectors a′ b′ c′ as integer combinations of a, b, c (e.g. a′ = 1 1 0, b′ = -1 1 0 for √2×√2 R45°). Presets fill in common rotated cells. A preview shows the atom count and the new cell; Create replaces the structure (undoable).

source
AtomBond.surface_dialog — Method

Open the Build surface window for viewer. With show=false the figure is built but not displayed (for tests).

AtomBond.edit! — Method
edit!(f, viewer, what; reframe=false, keep_selection=false)

Replace the crystal with f(crystal) as one undoable step. what describes the step for the status line ("delete 2 atoms"). Errors from f are shown in the status line and leave the structure unchanged. reframe re-aims the camera (for changes of cell size); keep_selection keeps the selected atoms (for edits that do not renumber them).

AtomBond.exit! — Method
exit!(viewer; force=false) -> Bool

Close the AtomBond window and its dialog windows (File → Exit, Ctrl+Q). With unsaved changes the first Exit only warns in the status line; a second Exit (with no edits in between) closes without saving. Returns whether it closed.
