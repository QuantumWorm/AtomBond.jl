Structures and elements

AtomBond.Crystal — Type
Crystal(lattice, species, frac; pbc=(true, true, true), title="", fixed, cell_constraints, charges, magmoms)

A structure: a Lattice, element symbols species and fractional coordinates frac (one per atom). pbc marks the periodic directions (a molecule has none). Optional per-atom data: fixed (which fractional x, y, z are fixed in a geometry optimization), charges (e) and magmoms (μB), with NaN for unknown; cell_constraints follows CASTEP's CELL_CONSTRAINTS for a b c α β γ. Crystals are immutable: editing functions return new ones.

AtomBond.wrap — Method
wrap(c; atoms=all, tol=1e-8) -> Crystal

Wrap atoms into the cell: map fractional coordinates into [0, 1) along periodic directions by adding whole lattice vectors (as ASE wrap, OVITO "wrap at periodic boundaries"). The structure itself does not change. atoms limits this to some atom indices; values within tol of 1 become 0.

One frame of a CASTEP .geom file, by default the last (the relaxed structure); frame may also be an index (1 = starting geometry).

source
AtomBond.read_castep_geom_frames — Method
read_castep_geom_frames(path or io) -> Vector{Crystal}

All frames of a CASTEP .geom (or .md) file: cell (<-- h) and Cartesian positions (<-- R), converted from Bohr to Å. Each frame's title gives its step and energy (Hartree in the file, shown in eV).

source
AtomBond.read_castep_output — Method
read_castep_output(path or io; charges=:mulliken) -> Crystal

CASTEP .castep output: the last unit cell ("Real Lattice(A)") and the last "Cell Contents" fractional coordinates, i.e. the final structure of a geometry optimization, with atomic charges from the last population analysis: charges = :mulliken (the "Charge (e)" column of "Atomic Populations (Mulliken)"; Hirshfeld charges when there are no Mulliken ones), :hirshfeld, or :none. Magnetic moments come from the Mulliken "Spin (hbar/2)" column of spin-polarized runs (hbar/2 units = μB).

AtomBond.kpoint_grid — Method
kpoint_grid(c; kspacing=0.25, min_gap=5.0) -> (n1, n2, n3)

Monkhorst–Pack / Γ-centred mesh for a k-point spacing in Å⁻¹ (2π included, as VASP's KSPACING; 0.25 is a reasonable default for semiconductors). Directions that are not periodic or that contain more than min_gap Å of vacuum get one k-point.

source
AtomBond.write_qe — Method
write_qe(path, c; kspacing=0.25, ecutwfc=40, pseudo="{El}.UPF", calculation=automatic)

pw.x input with ibrav = 0, the cell in Å and positions in crystal coordinates. pseudo is a file-name pattern in which {El} becomes the element symbol. ecutwfc is in Ry; check it against your pseudopotentials.

Constraints: fixed atoms get if_pos flags (0 = fixed; pw.x applies them to Cartesian force components, which equals fixing fractional coordinates only when the cell axes are along x, y, z; a fully fixed atom is always exact). calculation is by default 'scf' without constraints, 'relax' for a fixed cell and 'vc-relax' with cell_dofree otherwise (see cell_constraints_qe).

source

write_vasp_inputs(dir, c; kspacing=0.25) -> Vector of paths

AtomBond.load_structure — Method
load_structure(path) -> Crystal

Reads (format from the file name, see structure_format):

  • VASP: POSCAR/CONTCAR/.vasp, XDATCAR (last frame), vasprun.xml (final structure)
  • CASTEP: .cell, .geom (last frame, i.e. the relaxed structure), .castep output (final structure with Mulliken charges)
  • Quantum ESPRESSO: pw.x input .in/.pwi, pw.x output .out/.pwo (last structure)
  • FHI-aims geometry.in, SIESTA .fdf, ABINIT .abi/.abinit (and .in by content)
  • CIF, XYZ / extended XYZ, XSF (XCrySDen, VESTA), Gaussian cube, PDB
  • LAMMPS data (.lmp, .data, data.*), Materials Studio .car / .xsd, SHELX/AIRSS .res/.ins
source
AtomBond.save_structure — Method
save_structure(path, crystal; kwargs...)

Writer chosen by the file name: .cif (P1), POSCAR/CONTCAR/.vasp, .xyz/.extxyz, .in/.pwi (Quantum ESPRESSO, see write_qe), .cell (CASTEP, see write_castep), geometry.in (FHI-aims), .xsf, .pdb, .lmp/.data/.lammps (LAMMPS data), .car (Materials Studio), .res (SHELX/AIRSS). Keyword arguments (e.g. kspacing) go to the QE / CASTEP writers.

source
AtomBond.structure_format — Method
structure_format(path) -> Symbol or nothing

Which reader load_structure would use for this file name, or nothing: :cif, :xyz, :poscar, :xdatcar, :vasprun, :castep_cell, :castep_geom, :castep_out, :qe_in, :qe_out, :aims, :siesta, :abinit, :xsf, :cube, :pdb, :lammps, :car, :xsd, :res.

source
AtomBond.read_lammps_data — Method
read_lammps_data(path or io; style=nothing) -> Crystal

LAMMPS data file: box (with xy xz yz tilts), Masses and Atoms (atomic, charge or full style; taken from the "Atoms # style" comment or the number of columns). Each type's element is the element named in the Masses comment (1 28.0855 # Si), otherwise the one with the closest mass.

source
AtomBond.read_pdb — Method
read_pdb(path or io) -> Crystal

PDB: the cell from CRYST1 (a structure without one, or with the 1 Å placeholder cell, is boxed as a molecule) and ATOM / HETATM records of the first MODEL. The element comes from columns 77–78, otherwise from the atom name; a formal charge in columns 79–80 ("2+", "1-") is kept.

source
AtomBond.write_lammps_data — Method
write_lammps_data(path or io, crystal)

LAMMPS data file, atomic style (charge style when the structure has charges; unknown ones are written as 0): the cell in LAMMPS' restricted triclinic form (a along x, b in the xy plane; tilts written when non-zero), one atom type per element with the element named in the Masses comment.

source
AtomBond.write_pdb — Method
write_pdb(path or io, crystal)

PDB with CRYST1 (space group P 1) and HETATM records. Positions are Cartesian in the standard orientation (a along x, b in the xy plane), as PDB requires.

source
AtomBond.read_car — Method
read_car(path or io) -> Crystal

Materials Studio / Insight .car archive (version 3): the PBC line gives a b c α β γ, and atom lines give Cartesian Å positions with the element in the 8th column. Positions are taken in Materials Studio's default orientation (a along x, b in the xy plane). PBC=OFF files are boxed.

source
AtomBond.read_res — Method
read_res(path or io) -> Crystal

SHELX .res / .ins (AIRSS output included): CELL, LATT (centring, and inversion when positive), SYMM operations, SFAC element list and atom lines (name, SFAC number, fractional x y z). Symmetry-equivalent atoms are generated.

source
AtomBond.read_xsd — Method
read_xsd(path or io) -> Crystal

Materials Studio .xsd document: the lattice from SpaceGroup (AVector, BVector, CVector) and the Atom3d elements (fractional XYZ in a periodic document, Cartesian Å otherwise). Image atoms (ImageOf) are skipped; for a mixed-occupancy site the first component is used.

source
AtomBond.write_car — Method
write_car(path or io, crystal)

Materials Studio .car archive (PBC=ON with a b c α β γ and P1, or PBC=OFF), Cartesian positions in the standard orientation.

source
AtomBond.write_res — Method
write_res(path or io, crystal)

SHELX .res in P1 (LATT -1, no SYMM), as AIRSS writes it.

AtomBond.read_xsf — Method
